============================================================
SOLIDITY ENUM PROGRAM
============================================================

AIM:
To write and execute a Solidity program to demonstrate the use of enum.

SOFTWARE REQUIRED:
1. Remix IDE
2. Solidity Compiler
3. Remix VM (Cancun)

============================================================
PROGRAM
============================================================

STEP 1: OPEN REMIX IDE

Open the following website:

https://remix.ethereum.org/

Wait for Remix IDE to load.


============================================================
STEP 2: CREATE A SOLIDITY FILE
============================================================

1. On the left side, click "File Explorer".
2. Open the "contracts" folder.
3. Click the "+" button / New File.
4. Create a file named:

SimpleEnumExample.sol

5. Open the file.


============================================================
STEP 3: ENTER THE SOLIDITY CODE
============================================================

Copy and paste the following complete code into
SimpleEnumExample.sol:


------------------------------------------------------------
CODE START
------------------------------------------------------------

// SPDX-License-Identifier: GPL-3.0
pragma solidity 0.8.30;

contract SimpleEnumExample {

    // Define an enum for order status
    enum OrderStatus {
        Pending,
        Confirmed,
        Shipped,
        Delivered,
        Cancelled
    }

    // State variable using the enum
    OrderStatus public currentStatus;

    // Set initial status in constructor
    constructor() {
        currentStatus = OrderStatus.Pending;
    }

    // Function to update status
    function updateStatus(OrderStatus _newStatus) public {
        currentStatus = _newStatus;
    }

    // Get Status Strings
    function getStatusString()
        public
        view
        returns (string memory)
    {
        if (currentStatus == OrderStatus.Pending)
            return "Pending";

        if (currentStatus == OrderStatus.Confirmed)
            return "Confirmed";

        if (currentStatus == OrderStatus.Shipped)
            return "Shipped";

        if (currentStatus == OrderStatus.Delivered)
            return "Delivered";

        if (currentStatus == OrderStatus.Cancelled)
            return "Cancelled";

        return "Unknown";
    }

    // Get current status as uint
    function getStatusNumber() public view returns (uint) {
        return uint(currentStatus);
    }
}

------------------------------------------------------------
CODE END
------------------------------------------------------------


The enum contains five possible values:

Pending    = 0
Confirmed  = 1
Shipped    = 2
Delivered  = 3
Cancelled  = 4

These values are in the same order as the uploaded program.
