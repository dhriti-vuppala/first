============================================================
QUESTION 5 – 4 QUEENS PROBLEM IN PROLOG
============================================================

QUESTION:
---------
Write a program in Prolog to solve the 4-Queens Problem.


============================================================
SOFTWARE REQUIRED
============================================================

SWI-Prolog


============================================================
STEP 1 – CREATE THE PROLOG FILE
============================================================

Open Notepad or VS Code.

Create a new file named:

queens4.pl

IMPORTANT:
The file must end with .pl

Correct:
queens4.pl

Wrong:
queens4.pl.txt


============================================================
STEP 2 – ENTER THE PROGRAM
============================================================

Copy and paste the following complete code into queens4.pl:

------------------------------------------------------------

% ==========================================
% 4-QUEENS PROBLEM IN PROLOG
% ==========================================

% Entry point
solve_4_queens(Solution) :-
    Solution = [Q1, Q2, Q3, Q4],
    permutation([1,2,3,4], Solution),
    safe(Solution).

% Check that no two queens attack each other
safe([]).

safe([Queen|Others]) :-
    safe(Others),
    no_attack(Queen, Others, 1).

% Ensure no diagonal attacks
no_attack(_, [], _).

no_attack(Q, [Q1|Qs], D) :-
    Q =\= Q1 + D,
    Q =\= Q1 - D,
    D1 is D + 1,
    no_attack(Q, Qs, D1).

------------------------------------------------------------


============================================================
STEP 3 – SAVE THE FILE
============================================================

Save the file as:

queens4.pl

Example location:

C:\Users\YourName\Desktop\queens4.pl


============================================================
STEP 4 – OPEN SWI-PROLOG
============================================================

Open SWI-Prolog.

You should see:

?-


============================================================
STEP 5 – LOAD THE PROGRAM
============================================================

If queens4.pl is in the current directory, type:

?- [queens4].

Press ENTER.

Expected output:

true.


------------------------------------------------------------
IF THE FILE IS NOT IN THE CURRENT DIRECTORY
------------------------------------------------------------

Use the complete path.

Example:

?- consult('C:/Users/YourName/Desktop/queens4.pl').

IMPORTANT:
Use / instead of \ in the path.

Example:

?- consult('C:/Users/Dhriti/Desktop/queens4.pl').


============================================================
STEP 6 – RUN THE PROGRAM
============================================================

Type:

?- solve_4_queens(Solution).

Press ENTER.


============================================================
EXPECTED OUTPUT
============================================================

You should get:

Solution = [2,4,1,3] ;

The semicolon (;) means Prolog has another solution.

Press:

;

You should get:

Solution = [3,1,4,2] ;

Press:

;

again.

You should get:

false.

FINAL ANSWER
============================================================

The two solutions to the 4-Queens problem are:

[2,4,1,3]

[3,1,4,2]
