============================================================
QUESTION 6 – TRAVELING SALESMAN PROBLEM (TSP) IN PROLOG
============================================================

QUESTION:
---------
Write a program in Prolog to solve the Traveling Salesman
Problem.


============================================================
SOFTWARE REQUIRED
============================================================

SWI-Prolog


============================================================
GIVEN DISTANCES
============================================================

The graph contains four cities:

a
b
c
d


Distances:

a -> b = 10
a -> c = 15
a -> d = 20
b -> c = 35
b -> d = 25
c -> d = 30


The graph is undirected.

Therefore:

a -> b = b -> a = 10
a -> c = c -> a = 15
a -> d = d -> a = 20
b -> c = c -> b = 35
b -> d = d -> b = 25
c -> d = d -> c = 30


============================================================
STEP 1 – CREATE THE PROLOG FILE
============================================================

Open Notepad or VS Code.

Create a new file named:

tsp.pl

IMPORTANT:
The file must end with .pl

Correct:

tsp.pl

Wrong:

tsp.pl.txt


============================================================
STEP 2 – ENTER THE PROGRAM
============================================================

Copy and paste the following complete code into tsp.pl:

------------------------------------------------------------

% ==========================================
% TRAVELING SALESMAN PROBLEM IN PROLOG
% ==========================================

% Distance between cities

distance(a, b, 10).
distance(a, c, 15).
distance(a, d, 20).
distance(b, c, 35).
distance(b, d, 25).
distance(c, d, 30).

% Symmetric distances
% Since the graph is undirected,
% distance(X,Y) = distance(Y,X)

dist(X, Y, D) :-
    distance(X, Y, D).

dist(X, Y, D) :-
    distance(Y, X, D).

% Calculate total distance of a tour

tour_distance([_], 0).

tour_distance([City1, City2 | Rest], TotalDistance) :-
    dist(City1, City2, D),
    tour_distance([City2 | Rest], RestDistance),
    TotalDistance is D + RestDistance.

% Generate all possible tours

tsp(Start, Path, Cost) :-
    permutation([a,b,c,d], Perm),
    Perm = [Start|_],
    append(Perm, [Start], Path),
    tour_distance(Path, Cost).

% Find the shortest tour

shortest_tsp(Start, ShortestPath, MinCost) :-
    setof(
        [Cost, Path],
        tsp(Start, Path, Cost),
        Set
    ),
    Set = [[MinCost, ShortestPath] | _].

------------------------------------------------------------


============================================================
STEP 3 – SAVE THE FILE
============================================================

Save the file as:

tsp.pl

C:\Users\YourName\Desktop\tsp.pl

============================================================

Open SWI-Prolog.

?-


============================================================
STEP 5 – LOAD THE PROGRAM
============================================================

If tsp.pl is in the current directory, type:

?- [tsp].

Press ENTER.

Expected output:

true.


------------------------------------------------------------
IF THE FILE IS NOT IN THE CURRENT DIRECTORY
------------------------------------------------------------

Use the complete path.

Example:

?- consult('C:/Users/YourName/Desktop/tsp.pl').

IMPORTANT:
Use / instead of \ in the path.

Example:

?- consult('C:/Users/Dhriti/Desktop/tsp.pl').


============================================================
STEP 6 – FIND THE SHORTEST TOUR
============================================================

Type:

?- shortest_tsp(a, Path, Cost).

Press ENTER.


============================================================
EXPECTED OUTPUT
============================================================

You should get:

Path = [a,b,d,c,a],
Cost = 80.
